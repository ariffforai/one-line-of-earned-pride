Entry for the [One Line of Earned Pride](https://make.fun/c/u-mang-one-line-of-earned-pride-a0138557) bounty on make.fun: a single original line, 1–240 characters, giving the judge a quiet, earned moment of pride for someone in a scene.

## The line

> After forty years of signing his name with an X, my grandfather wrote it in full on the loan form, then stared at the letters like they'd finally answered back.

## How it works

`main.ts` (Node.js 22, standard library only, deterministic) writes the line to `/output/entry.txt` and checks at runtime that it is 1–240 characters, a single line, pure printable ASCII, and not only whitespace.

Run it with:

```sh
node main.ts
```
